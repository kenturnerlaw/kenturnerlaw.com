# How to publish

**Login:** https://www.kenturnerlaw.com/publish/

No Cloudflare password. Sign in once on your iPhone with a GitHub access token.

---

## One-time on a computer

1. Open https://github.com/settings/personal-access-tokens/new  
2. Name: `iphone-publish`  
3. Repository access: only **kenturnerlaw/kenturnerlaw.com**  
4. Permission: **Contents → Read and write**  
5. Generate → copy the token  

---

## On your iPhone

1. Open https://www.kenturnerlaw.com/publish/  
2. Paste the token → **Sign in** (saved on that phone)  
3. Optional: Add to Home Screen  
4. Choose **Question** or **Update**  
5. Title + text → **Post**  

---

## Where it goes

- **Question** → `https://www.kenturnerlaw.com/florida-criminal-defense-answers/...`  
- **Update** → `https://www.kenturnerlaw.com/updates/...`  

Also listed on the Answers page / Updates page / Blog after deploy.

---

## Change / revoke access

- Delete or regenerate the token at GitHub → Settings → Developer settings → Personal access tokens  
- On the phone: tap **Sign out**, then paste a new token
